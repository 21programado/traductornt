Conseguir una API Key gratis

Esta aplicación usa Gemini, de Google, y necesita una clave personal. Es gratuita y no pide tarjeta.

  1. Entra a aistudio.google.com/apikey e inicia sesión con tu cuenta de Google.
  2. Toca Crear clave de API (Create API key). Si te pide elegir un proyecto, crea uno nuevo o usa el que aparezca.
  3. Copia la clave que se genera.
  4. Vuelve a esta aplicación, toca Ajustes, pégala y guarda. Solo hace falta una vez en cada navegador.
No actives la facturación Mientras el proyecto no tenga facturación, la clave es gratuita: si llegas al límite de uso, simplemente esperas.
Límites de uso La capa gratuita tiene un tope de consultas por minuto y por día, que Google puede cambiar. Si se agotan, la aplicación lo avisa; prueba de nuevo más tarde. Puedes ver tus límites en Google AI Studio.
Privacidad Con la capa gratuita, Google puede usar lo que envías para mejorar sus productos. Un texto bíblico no suele ser delicado, pero no pegues nada personal.
Cuida tu clave Es como una contraseña: quien la tenga puede gastar tu cupo. No la compartas. En esta aplicación se guarda solo en este navegador.

Los nombres de los botones en Google pueden cambiar. Si algo no coincide, busca la opción de crear una clave de API.
